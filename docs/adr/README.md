## ADR template

모든 ADR은 [TEMPLATE.md](./TEMPLATE.md)의 12개 섹션을 반드시 포함한다:

Problem · Requirements · Candidates · Benchmark · Security · Cost · Vendor lock-in · Operational burden · Migration difficulty · Recommendation · Rejection reasons · Exit strategy
